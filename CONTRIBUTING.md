# Contribuindo

Este é um projeto interno do bot_marc.

Ajustes, correções e novas funcionalidades são feitos diretamente neste
repositório. Antes de abrir um PR:

1. Rode os testes: `npm run test:all` e `npm run test`.
2. Mantenha o padrão de código e a estrutura de pastas já existentes.
3. Descreva no PR o que mudou e por quê.
